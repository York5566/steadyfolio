# 慢慢投 Steadyfolio · 網頁獨立版

把台灣與美國股票／ETF 的長期定期定額，放到同一筆預算、同一種幣別下比較。這是獨立專案，不修改原有桌面版、50 組版或其設定與資料。

## 目前完成

- 繁體中文／英文，靜態介紹、FAQ、計算方法、隱私與資料風險頁。
- 最多 12 組、12 個不同標的；單一股票或自訂權重配置；初始投入、每月扣款日、買入成本。
- TWD／USD 預算與報表，歷史匯率換算；缺匯率不猜、不拿未來值回填。
- 輸入台股／美股代碼，自動取得歷史價格；沿用桌面版資料來源，無須 CSV、Python 或手動灌入資料庫。
- 本金、損益、XIRR、TWR、最大回撤、年度報酬；共同期間與來源揭露。
- 四種可縮放圖表、1／3／5 年快捷區間、可切換圖例、排序比較表、PNG／CSV／分析 JSON／列印。
- 匿名分享完整輸入快照，30 天到期；朋友可直接看、接續自己的分析；管理檔可撤銷。
- Worker API、D1、Turnstile、限流、原子配額、安全標頭、正式部署檢查及 GitHub Actions。

## 先看本機版本

安裝 Node.js 24 LTS（含 npm），在本資料夾執行 `啟動本機預覽.cmd`。第一次會安裝鎖定相依套件、建立僅供本機的設定及 D1、建置網站；保持視窗開啟。開啟：

- <http://127.0.0.1:5173/zh-Hant/>
- <http://127.0.0.1:5173/en/>

本機分享只在這台電腦有效，不能直接傳給外網朋友。正式部署後會自動產生正式網址。

手動啟動方式：

```powershell
npm ci
Copy-Item .dev.vars.example .dev.vars
npm run db:local
npm run build
npx wrangler dev --ip 127.0.0.1 --port 5173
```

`.dev.vars` 僅限本機，不能提交或用於公開服務。若已經存在，請勿覆蓋。正式部署方法見 [DEPLOYMENT.md](DEPLOYMENT.md)。修改程式後先停止預覽、重新 build 再啟動；Vite 開發可使用 `npm run dev:api` 與另一視窗 `npm run dev`。

## 使用順序

1. 先選投入／結果幣別，再填金額與期間。切換幣別**不會自動換算已輸入數字**。
2. 開啟網站自動抓取 0050、VTI、QQQ 與所需匯率；按「新增標的」可選常用清單或輸入代碼。上市可輸入 0050／2330.TW，上櫃如 6488.TWO，美股如 AAPL。合成示範須另外選取，只使用 DEMO 代碼。
3. 加入股票或配置；每一組獨立使用同一筆預算，並非把預算分給各組。
4. 按「比較長期表現」。改變期間後自動補抓資料；0050 延長期間只抓缺段與銜接月份，跨幣別取得聯準會 H.10／FRED 匯率。完全空庫的首次長歷史仍可能需數分鐘，已完成月份保留快取。錯誤會跳出視窗並在比較按鈕旁顯示；更新失敗明確標示上次結果期間，禁止把未更新的結果直接分享。匯出仍是已完成的那份分析。
5. 核對共同期間、來源與假設。圖表縮放只改變視野，不會改變摘要的統計期間。
6. 分享前移除個資，確認資料分發權。保存管理檔，不能把含撤銷密鑰的管理檔傳給朋友。

### 資料與分析檔

價格 CSV 匯入已移除；每日績效 CSV 匯出保留。JSON 分析檔與分享快照可繼續開啟，保留原有結果；選「自動抓取歷史行情」後，可用原設定重新抓取與比較。

報價幣別由來源驗證，`USDTWD` 為 **1 USD 兌多少 TWD**。最多每檔 12,000 筆、分析檔 4 MB；分享 JSON 上限 512 KiB，太大請縮短期間／標的或改用分析檔。資料來源失敗時停止計算並保留上次結果，不補假價格。

## 真實行情與授權

依「免費優先，找不到先用原本的」選擇，Worker 已直接接上桌面版同源資料：0050 使用證交所收盤價、元大配息與證交所分割；其他台美標的使用 Yahoo 含息還原價；匯率使用聯準會 H.10／FRED。Python 轉接器僅保留供維護比對，不是網站使用前置步驟。原始研究資料不隨 ZIP 或 GitHub 發布，公開分享仍保留研究資料限制。

目前尚未確認能免費涵蓋「台美長期含息還原價 + 公開網頁 + 瀏覽器傳送 + 快照分享／下載」的完整方案。台灣政府開放資料有可商用的部分日行情，但不足以直接替代完整資料鏈。**免費取得 ≠ 可公開商用分發。**詳見 [DATA_SOURCES.md](DATA_SOURCES.md)；不是已取得商用授權的承諾。

## 維護與驗證

```powershell
npm run check
npm audit --omit=dev
$env:TEST_API_ORIGIN='http://127.0.0.1:5173'
npm run test:api
npx tsx scripts/market-smoke.ts
npx wrangler deploy --dry-run
```

`test:api` **只允許本機開發環境**，會建立並撤銷自己的測試快照。正式環境另依部署清單手動驗收。計算規則詳見網站「計算方法」。

`market-smoke.ts` 使用空的記憶體 SQLite 及真實 HTTP 來源，測試台灣上市／上櫃、美股、匯率、0050 分割／配息與快取；會使用來源下載額度，但不修改現有資料庫，不寫入原始行情到驗證報告。
